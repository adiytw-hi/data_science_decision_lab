Model and accessibility notes

A linear classifier can only make straight boundaries in 2D. Manual editing after training changes the fitted coefficients, so all metrics and both curves are recomputed. Undefined rates display “N/A” rather than inventing zero. Use the selected-sample editor and 3D orbit buttons if dragging is difficult. On the focused 2D plot, arrow keys move the selected dot; Enter selects the next dot or inserts a dot at (0,0) in Add mode.

For actual evaluation: use separate held-out data, address leakage, inspect class-specific error costs, validate subgroup data quality, and check calibration and uncertainty.

BoundaryLab is a conceptual education aid. Data remain inside the browser; exports are generated locally. No accounts, data uploads, or external dependencies.
